# 开发日志 · 2026-10-28

项目：课迹 CourseTrail（跨学期课堂记忆库）
开发方式：全程在 Qoder Desktop 内完成，未使用其他 AI IDE 编写核心代码。

## 1. 选题收敛

Qoder 把题目里的三个痛点（文献综述、周报拼接、跨学期笔记）拆成「用户 / 数据来源 / 技术承重点」三列对比，并给出四个方向的功能边界与演示脚本。人工判断后选择学生场景，原因是数据可以自己造、演示不依赖他人隐私。随后删掉 PowerContext，只保留 seekdb，减少一个服务与一类故障。

## 2. 环境与数据库验证

- 启动 Docker Desktop 后发现 Docker Hub 连接超时，改用镜像源拉取 `oceanbase/seekdb`。
- Qoder 编写探针脚本 `scripts/probe.mjs`，逐条验证：
  - `VECTOR(4)` + `VECTOR INDEX … WITH (DISTANCE=COSINE, TYPE=HNSW, LIB=VSAG)`
  - `FULLTEXT INDEX … WITH PARSER ik`（中文分词可用，`MATCH … AGAINST('贝叶斯')` 能命中）
  - `cosine_distance()` / `l2_distance()` / `inner_product()` 均可用
- 结论：单表同时建两类索引可行，混合检索不需要在应用层拼两个库。

## 3. 数据层

表结构：`courses` / `materials` / `chunks` / `concepts` / `chunk_concepts` / `cards` / `reviews` / `prefs`。

`chunks` 同时持有 `embedding VECTOR(1024)`、IK 全文索引、`course_id` 冗余列，保证筛选不用回表。

## 4. 入库管线

- PDF：pdfjs-dist 逐页抽取文字并保留页码。
- 图片：有视觉模型时转写为文字（公式用 LaTeX），否则使用用户填写的说明。
- 文字：直接切块入库，同时落一份 txt 作为原文。
- 向量：优先调用 OpenAI 兼容的 embedding 接口；未配置时使用本地 2/3-gram 特征哈希向量，保证离线可跑。
- 切块：从 480 字调整到 260 字，并按句子边界回溯重叠，避免片段从半句话开始。

## 5. 检索

第一版排序出现了严重噪声：查询「贝叶斯 后验」返回 15 条，其中 13 条只是弱关键词命中（相关度 0.2 左右）。原因是 IK 会把查询拆成更细的 token，`MATCH` 对单字也有分数。

修复：
- SQL 内的排序表达式与前端展示分数保持同一公式；
- 相关度低于 0.6 的关键词分数归零；
- 两路分数都低于阈值的行在应用层过滤。

修复后同一查询只返回 2 条，均为真正相关片段。

## 6. 复习

使用 ts-fsrs 5.4.2。评分 1–4 映射到 Again/Hard/Good/Easy，更新 `due / stability / difficulty / reps / lapses / state`，并写入 `reviews` 日志表。

示例课程补充了 16 张手写问答卡（覆盖贝叶斯、SVD、过拟合等），其余片段使用基于小标题的模板卡。

## 7. 踩坑记录

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 整站没有样式，`@theme` 报 Unknown at rule | 缺少 PostCSS 配置 | 安装 `@tailwindcss/postcss` 并新增 `postcss.config.mjs` |
| 上传 PDF 返回 500：`doc.destroy is not a function` | pdfjs v5 的文档对象只有 `cleanup()` | 改为 `await doc.cleanup()` |
| `/api/files/[id]` 触发 Jest worker 崩溃 | Turbopack 下 Node 流转 Web Stream 不稳定 | 改为 `readFile` 后直接返回 `Uint8Array`，并重启 dev server 清掉已崩溃的 worker |
| 复习接口返回「卡片不存在」 | 测试时用了已被重建流程删除的卡 id | 改用当前队列里的卡 id 重新验证 |
| 种子数据每份资料只有 1 个片段 | 切块上限 480 字，示例文本不足 | 上限降到 260 字 |
| 部分资料显示 0 张卡 | 手写卡只覆盖了部分片段 | 为未覆盖片段补模板卡 |

## 8. 验收

- `npx tsc --noEmit` 通过
- `npm run lint` 通过
- `npm run build` 通过（全部页面动态渲染）
- 端到端：上传 2 页 PDF → 4 个片段（页码 1/2）→ 检索命中 → 打开原文；上传图片 → 说明参与检索 → 缩略图展示；复习评分 → due 顺延、统计更新。
