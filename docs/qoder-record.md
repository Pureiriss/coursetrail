## 2. 关键对话（摘要）

1. **需求**：从零开发一个解决真实痛点的作品，核心功能结合 seekdb。
   **Qoder**：给出四个方向对比，推荐「文献对比工作台」；用户改为「课程记忆库」。
2. **取舍**：用户要求「只保留 seekdb，越方便越快越好」。
   **Qoder**：把架构收敛为单语言全栈（Next.js + mysql2 + seekdb），去掉独立 Python 服务与 PowerContext。
3. **验证**：Qoder 先用探针脚本确认 `FULLTEXT … WITH PARSER ik`、`VECTOR … TYPE=HNSW`、`cosine_distance()` 可用，再生成业务代码。
4. **调优**：第一版检索返回 15 条、13 条为噪声；Qoder 加入相关度阈值并统一 SQL 与前端分数公式，同一查询降为 2 条。
5. **发布**：Qoder 生成静态门户、打包为 Sites 草稿、发布并把可见范围改为公开。
